# LogicLab delivery outcomes

## Interactive circuit workspace
- [x] Provide an interactive circuit workspace for placing and connecting digital logic components.
- [x] Show visible wires between connected nodes and make live signal values readable on the workspace.
- [x] Provide clear validation and feedback for invalid, incomplete, or cyclic circuit configurations.

## Logic gates and flip-flops
- [x] Support common logic gates: AND, OR, NOT, NAND, NOR, XOR, and XNOR.
- [x] Support flip-flops with clocked state behavior, including clock/data controls and visible Q state.
- [x] Provide configurable binary inputs and visible output indicators.

## Simulation controls
- [x] Provide Run, Pause, Reset, and Step controls for the circuit simulation.
- [x] Propagate signals in real time and expose a clock control for sequential circuits.

## Truth tables
- [x] Automatically generate a truth table for compatible combinational circuits.
- [x] Let the user switch between gate and flip-flop lab presets while keeping the current simulation understandable.
